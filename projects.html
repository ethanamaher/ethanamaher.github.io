Real-Time DNS Provenance Monitor (Internal Research Project), Private Repository 2025
- Developed a C# application to correlate raw network events with DNS query logs, turning ambiguous IP alerts into domain names, offering a greater view on indicators of compromise
- Provides real-time visibility into DNS and system network activity by streaming raw DNS events over ETW and system provenance events from machines in the network
- Designed the application asynchronously to handle multiple concurrent, high-volume event streams with minimal performance overhead
